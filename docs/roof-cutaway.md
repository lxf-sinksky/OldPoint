# 建筑屋顶隐藏

俯视模式默认对选中的建筑整体掀顶。所在建筑和相机判定需要掀开的其他建筑共用同一组建筑选择；屋顶部件不再逐块进行视线投影。墙体仍按现有墙段遮挡规则处理。

## 捕获与绘制

- `RoofCutaway` 分帧捕获附近屋顶身份、贴图范围、模型范围及所属建筑。只发布完成的候选扫描；约 250 毫秒后刷新。候选范围最多扩展至人物各方向 48 格，缓存最多保留 4096 个候选。
- `RoofSelection` 优先采用明确的建筑归属。只有无归属的屋檐使用选中范围外扩一格的回退；不高于人物脚下地面的屋顶保持显示。
- `RoofBounds` 记录贴图区域或模型身份和隐藏决定；`OcclusionRules` 统一打包供普通与 Iris 绘制消费。
- `GeneratedRoofs` 在 Viewpoint 的屋顶和山墙生成出口标记顶点。原有面和补出的面一起保留身份，不依赖材质名称；`SurfaceCeilings` 衔接已支持的 Surface Fix 生成路径。
- 原生生成入口有三个参数。ZombieBuddy 的严格匹配补丁必须显式绑定这些参数；只声明返回值会被当作无参数匹配，挂接日志不能证明实际匹配成功。
- `RoofModels` 保存每个场景的模型实例掩码。阴影阶段保留屋顶投射物，避免掀顶同时改变室内照明。

## 调试

Delete 菜单的 OldPoint 页面有独立“调试”页，保留两个默认关闭的选项：

- 屋顶调试变色：红色为本应隐藏、绿色为保留。调试时暂时显示这些屋顶，关闭后恢复实际隐藏。
- 鼠标射线命中调试：青色命中点、黄色几何法线、蓝色附近同平面高亮，以及坐标、规则数量和附近物件线索。

法线由同帧 3×3 深度样本估算，混合表面、边缘或无效样本不输出法线。蓝色仅标出命中平面，不代表屋顶分类。附近物件是线索，不是精确命中身份；生成面可通过来源标记隐藏，因此零贴图规则不能单独证明漏识别。

从绘制坐标还原楼层高度必须调用该位置的 `FarRelief.Lift.scene(x, y)`，与原生 MousePick 一致，不能扣除全局 `sink`。调试深度读取后恢复 OpenGL 读取与 pixel-pack 状态，不修改借用的网格或原生缓冲。

## 验证与局限

默认测试覆盖建筑归属、屋檐回退、楼层保护、GPU 规则、真实 ZombieBuddy 匹配、实际方法内联、普通/Iris 材质输出、法线与地形高度还原。用户已对建筑屋顶和补面隐藏进行游戏内验证；不同地图、模型包、光影包仍需各自检查。任意外部模组补面只有进入已支持的来源路径或身份识别后才会纳入。
